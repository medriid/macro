# Authentication Tokens

This directory stores your encrypted authentication token.

## How to Get Your Token

1. Visit: https://themedium.in/auth/start
2. Click "Login with Discord"
3. Authorize the application
4. Copy your token
5. Paste it into the MEDIUM Macro login screen

## Security

- Tokens are encrypted using machine-specific keys (Computer Name + Username)
- Never share your token with anyone
- If you suspect your token is compromised, logout and generate a new one

## Troubleshooting

If you're having login issues:
- Make sure you're in the Discord server
- Verify you have the paid access role
- Try logging out and generating a new token
- Check your internet connection
